Conexiones ADB

—

Conecta primero por USB, activa el modo WiFi y luego pulsa «Conectar» con la IP del teléfono. Después podrás desenchufar el cable.

Volver a USB

Desactiva el ADB inalámbrico y deja el teléfono escuchando solo por USB.

Si el teléfono se reinicia o cambia de red, la IP puede cambiar: reconéctalo por USB o vuelve a conectar con la nueva IP.

Acciones de energía

«Apagar» y «Reiniciar» usan adb reboot. Encender de nuevo un teléfono apagado no es posible por ADB: hay que pulsar el botón físico. Bloquear apaga la pantalla; si el teléfono tiene PIN/patrón, no se puede saltar el bloqueo de seguridad.

Shell ADB

$ adb shell — listo. Escribe un comando y pulsa Ejecutar.

El comando se ejecuta como usuario shell en el teléfono. Sin root no puede leer datos privados de otras apps ni modificar el sistema.
